Personal Profile Web Application

1. Introduction

This project is developed for CSC584 Individual Assignment 1. The purpose of this application is to create a simple Personal Profile Web Application using HTML, Java Servlet and JSP.

The application allows users to enter their personal information through a form. After submitting the form, the information will be processed by a Java Servlet and displayed on another page.

2. Technologies Used

The following technologies are used to develop this application:

HTML – Used to create the personal profile form.
CSS – Used to make the web pages look neat and attractive.
Java Servlet – Used to receive and process the information submitted by users.
JSP – Used to display the submitted personal information.
NetBeans IDE 8.2 – Used to write and manage the project code.
GlassFish Server 4.1.1 – Used to run the web application.
JDK 1.8 – Used for Java development.

3. Application Features

Users can enter the following information:

Name
Student ID
Programme
Email
Hobbies
Short Self-Introduction

After clicking the Submit Profile button, the application will display the information entered by the user.

4. How the Application Works

The application works in three main steps:
Users open the index.html page and fill in the personal profile form.
The submitted information is sent to ProfileServlet.java using the HTTP POST method.
The Servlet processes the information and sends it to profile.jsp for display.

5. Project Files

This project consists of several files, each with its own function. 
The index.html file is used to create the personal profile form where users enter their information. 
The index.jsp file redirects users to the main form. 
The ProfileServlet.java file receives and processes the information submitted through the form. 
Next, the profile.jsp file displays the submitted personal information. 
Lastly, the style.css file is used to improve the appearance and layout of the application.
